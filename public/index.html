A FEW THINGS YOU MIGHT WONDER

Clear from
the beginning.

Is the website demo using live AI?

The public example runs locally using rules and templates, so you can try it without sending your message to an AI provider. The separate protected workflow uses an AI API when configured and saves drafts to a review inbox.

Can this work with our existing tools?

We start by checking the tools you use and the access they support. Email, forms, calendars and CRM connections are scoped for each project; the public example demonstrates the workflow before those connections are added.

Will AI send messages without our approval?

The starter system prepares replies and saves them for review. Approving a draft marks it reviewed; it does not send a message. Any future sending or booking step needs its own configured integration and agreed rules.

How is a project priced?

Scope comes first. The workflow, integrations, review requirements and ongoing support determine the proposal. AI provider and third-party subscription costs are discussed separately.
